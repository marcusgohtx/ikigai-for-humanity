# Ikigai for Humanity

- Hosted multiplayer source lives in sites/ikigai-for-humanity/. Read its README before changing or publishing the game.
- GitHub Pages redirects to the ChatGPT Site. The original static game source remains in public/.
- Preserve localStorage keys and multiplayer room URL parameters.
- Keep assets relative so GitHub Pages subpath hosting works.
- Run npm run lint and npm run build before publishing.
- In completion reports, state Git status separately from Sites deployment status: name the branch and commit, whether changes were pushed directly or merged through a PR, and the deployed version/URL or that no deployment was performed.
